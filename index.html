🔥 Setup Firebase

✅ Firebase gratis untuk usaha kecil. Panduan lengkap ada di file README.md di folder aplikasi.

  1. Buka console.firebase.google.com → Login dengan Gmail
  2. Create project → beri nama (misal: fnb-manager-saya)
  3. Daftarkan Web App (</>) → salin firebaseConfig
  4. Build → Realtime Database → Create Database → Singapore → Test mode
  5. Build → Authentication → Email/Password → aktifkan → Add user (email + password login Anda)
  6. Tempel firebaseConfig ke file index.html, ganti nilai PASTE_...

🐙 GitHub Pages

  1. github.com → + New repository → nama: fnb-manager → Public
  2. Upload index.html → Commit changes
  3. Settings → Pages → Source: main / (root) → Save
  4. Firebase → Authentication → Settings → Authorized domains → Add domain: username.github.io
  5. Akses di: https://username.github.io/fnb-manager/

🧾 Resep Produk & Integrasi Stok

✅ Fitur ini adalah inti manajemen produksi. Bahan baku berkurang otomatis sesuai resep setiap kali ada penjualan!

Cara Membuat Resep

  1. Pastikan menu/produk sudah dibuat di Menu/Produk
  2. Pastikan bahan baku sudah didaftarkan di Stok Bahan Baku
  3. Buka Resep & Produksi → Daftar Resep → Buat Resep
  4. Pilih produk, lalu klik + Tambah Bahan
  5. Untuk setiap bahan: pilih dari stok, isi jumlah per 1 porsi
  6. Contoh: Kentang Crispy = tepung terigu 50 gram + kentang 200 gram + garam 3 gram + minyak 20 ml
  7. Simpan resep

Alur Integrasi Otomatis

📱 Kasir catat penjualan 2 porsi Kentang Crispy

⬇️ Sistem cek resep Kentang Crispy

⬇️ Stok tepung terigu berkurang 100 gram (50g × 2)

⬇️ Stok kentang berkurang 400 gram (200g × 2)

⬇️ Stok garam berkurang 6 gram (3g × 2)

⬇️ Tercatat di Riwayat Stok sebagai "Penjualan Kasir"

Produksi Manual

Jika Anda memasak dalam batch (misal: bikin 20 porsi sekaligus), gunakan Produksi Manual. Bahan langsung dipotong dari stok sejumlah porsi × resep.

Indikator di Kasir

  • 🟢 Cukup — stok memadai untuk buat porsi tersebut
  • 🟡 Terbatas — stok hanya cukup untuk beberapa porsi lagi
  • 🔴 Stok Habis — tidak bisa produksi (tapi masih bisa dijual manual)

⚠️ Jika produk tidak punya resep, penjualan di kasir tidak memotong stok apapun. Pastikan semua produk sudah dibuatkan resepnya!

🚀 Mulai Cepat (Urutan yang Benar)

  1. Daftarkan Bahan Baku — Stok Bahan Baku → Tambah Bahan
  2. Tambahkan Menu — Menu/Produk → Tambah Menu
  3. Buat Resep setiap Menu — Resep & Produksi → Buat Resep (PENTING!)
  4. Catat Modal Awal — Modal & Hutang → Tambah Modal
  5. Buka Kasir — saat jual, bahan otomatis berkurang sesuai resep
  6. Pantau Dashboard — grafik, stok menipis, laba bersih

📤 Ekspor Data ke Excel

  1. Buka menu Ekspor Data
  2. Pilih rentang: Semua / Per Tahun / Per Bulan
  3. Klik kartu yang ingin diekspor
  4. File .xlsx terunduh otomatis

💡 Ekspor rutin tiap akhir bulan sebagai backup tambahan selain Firebase.
